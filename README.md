# ☕ Bean-Grinder

> **Codebase Modernization, Legacy AST Decomposition & Migration Planning Engine.**

---

## ☕ Why "The Grinder"?

You cannot brew whole coffee beans; they must be ground into uniform particles for balanced extraction. In legacy software systems, monolithic codebases must be ground down into manageable syntactic units and clean architectural seams. **`bean-grinder`** analyzes AST structures, maps dependencies, identifies seams, and synthesizes migration plans (`05_PLAN.md`).

---

## 🚀 Capabilities & Agents

| Capability / Agent | Description |
| :--- | :--- |
| **`@ast-grinder` & `@graphify-scout`** | Maps AST topologies, call graphs, and coupling hotspots across legacy codebases. |
| **`@seam-scout` & `seam-extraction`** | Identifies modular seams and anti-corruption layer boundaries. |
| **`@synthesis-agent` & `synthesize`** | Assembles vertical, dependency-ordered modernization slices into OKF-compatible `05_PLAN.md`. |
| **Reviewer Panel** | Quad-persona review panel (`@reviewer-pm`, `@reviewer-architect`, `@reviewer-engineer`, `@reviewer-exec`) evaluating feasibility and business impact. |
| **`@runtime-parity-verifier`** | Verifies behavioral and runtime parity between legacy and modernized systems. |
